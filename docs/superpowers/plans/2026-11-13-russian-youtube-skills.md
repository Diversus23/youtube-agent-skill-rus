# Russian YouTube Skills Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans. Use a fresh reviewer for final validation.

**Goal:** Универсальный русскоязычный набор из 11 skills и 6 рабочих CLI.
**Architecture:** Сохраняем расположение исходных skills и взаимные зависимости. Профиль `youtube/voice.md` принадлежит проекту пользователя и необязателен. Python-инструменты работают на стандартной библиотеке.
**Tech Stack:** Markdown, JSON, Python 3.10+, unittest.
**Spec:** `docs/superpowers/specs/2026-11-13-russian-youtube-skills-design.md` (одобрен пользователем «делай»).

## Global Constraints

- Исходный репозиторий не изменять; сохранять MIT-атрибуцию.
- Не публиковать и не устанавливать набор глобально.
- Поддерживать кириллицу, ё, смешанные названия и UTF-8.
- Не выдавать эвристики за прогнозы или причинные диагнозы.

## Review Focus

- UTF-8 BOM и смешанный русский/английский текст: тесты токенизации и файлового ввода.
- Проценты и секунды в коротком видео: явная ось, без угадывания по максимальному значению.
- Некорректные, пустые и нечисловые данные: понятная ошибка CLI без успешного ложного отчёта.
- Установка полного набора: проверить соседние импорты и ссылки.
- Нет профиля автора: выполнить сценарий без запроса трёх видео или записи глобальных файлов.

## Execution notes

Пользователь одобрил реализацию. Дополнительное согласование процесса не требуется. Работа выполняется в выделенном пользователем репозитории `youtube-agent-skill-rus`; исходник остаётся только для чтения. Изменения остаются доступными для просмотра, без push и публикации.

Кодировка: передача русского текста через PowerShell pipe первоначально заменила кириллицу на `?`. Повреждённые файлы восстановлены прямой записью UTF-8; регрессионная проверка сначала обнаружила 23 повреждённых файла, после восстановления проходит. Генератор восстановления удалён. Английские инструкции записаны по последующему пожеланию пользователя, не как обход ошибки кодировки.

Валидатор skill-creator требует PyYAML, хотя сами инструменты не имеют внешних зависимостей. PyYAML установлен только в игнорируемую `.superpowers/validation-deps` для проверки разработки.

Границы независимой проверки: сценарии поведения проверены чтением инструкций и запусками инструментов, не отдельными установленными сессиями Codex/Claude. Правила платформы проверены исполнителем по официальной справке. Прогностическая точность эвристик не заявляется; публикация и доступность функций аккаунта не тестировались, так как набор не подключается к аккаунтам.

# Универсальный набор YouTube skills на русском

## Назначение

Адаптировать `C:/Projects/youtube-agent-skill` для любого русскоязычного YouTube-канала. Пользователь уточнил: набор должен быть универсальным, а не настроенным под один канал.

## Подход

Сохранить отдельные skills (теперь 12, включая `yt-voice`) и 6 CLI-инструментов. По уточнению пользователя инструкции для агента остаются на английском, а язык результата по умолчанию — русский. Русские примеры, словари, шаблон профиля и сообщения CLI поддерживают работу с русскоязычным контентом. Пользователь затем одобрил перенос всех инструментов на Node.js 22.20+ для единственного окружения выполнения. Сохранить работу без сторонних библиотек и исходную MIT-атрибуцию.

Рассмотренные альтернативы: перевод только Markdown оставляет инструменты без поддержки русского; единый большой skill усложняет выбор отдельных задач. Пользователь одобрил адаптацию набора, затем предложил оставить агентские инструкции на английском для компактности. Это уточнение принято.

## Изменения

- Поддержать кириллицу, ё, смешанные русско-английские названия и UTF-8; добавить русские словари и шаблоны распознавания.
- Сохранить сценарии, упаковку, монтаж, комментарии, планирование, исследование ниши, удержание, Shorts, SEO, главы и аудит.
- Сделать профиль автора необязательным и локальным для проекта. Не требовать три видео перед каждой задачей, не создавать глобальный профиль молча. При отсутствии профиля использовать нейтральный русский и сведения текущего запроса.
- Убрать неподтверждённые универсальные диагнозы и обязательные частоты публикаций. Оценки хуков и заголовков обозначать как эвристики, не прогноз просмотров. Русская версия не наследует заявления о калибровке английских эвристик.
- Исправить выявленные ошибки: обработку JSON-массива расшифровки, расхождение ограничения слов на обложке с проверкой, неоднозначность секунд и процентов в удержании. Добавить явные единицы и поддержку CSV с десятичной запятой.
- Проверить актуальные требования YouTube по официальной документации перед включением в инструкции; отличать требования платформы от рекомендаций.
- Подготовить русскую документацию по установке и использованию в Codex и Claude Code. Проверить взаимные пути зависимых skills; набор устанавливается целиком.

## Границы

Не публиковать видео и комментарии, не подключать аккаунты, не устанавливать набор глобально в рамках разработки. Не переносить личные данные канала. Исходный репозиторий не изменять.

## Проверка

Проверить структуру и frontmatter всех skills, внутренние ссылки, Node.js CLI и русскоязычные примеры. Регрессионные проверки должны покрывать кириллицу, совпадение текста заголовка и обложки, повторы речи, JSON-массивы, границы глав и единицы CSV. Проверить сценарий использования без профиля автора. Данные для проверок синтетические и явно обозначены. План переноса: `docs/superpowers/plans/2026-11-13-node-migration.md`.

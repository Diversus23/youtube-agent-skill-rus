# YouTube Agent Skills — русский контент

12 навыков для подготовки и анализа YouTube-видео: от настройки голоса автора до сценария и разбора удержания. Подходят любому русскоязычному каналу; ниша, регион и стиль не зашиты в набор.

**Инструкции для агента написаны на английском. Результат по умолчанию — на русском.** По запросу можно сменить язык. Примеры хуков и шаблон авторского профиля русские; инструменты распознают кириллицу, ё и смешанные названия вроде YouTube или DaVinci Resolve.

Набор готовит материалы, но не публикует их и не подключается к аккаунту. Для шести инструментов нужен **только Node.js 22.20 или новее**. Python, сторонние библиотеки, сборка и `npm install` не нужны. Текстовые задачи можно выполнять без запуска инструментов. Для исследования актуальной ниши агенту нужен доступ к поиску либо ваша подборка данных.

## Установка

### Через npx

При наличии Node.js 22.20+ и `npx` установите весь набор одной командой, затем выберите агента в меню:

```sh
npx skills add Diversus23/youtube-agent-skill-rus --skill '*'
```

Флаг `--skill '*'` выбирает все 12 навыков: они используют общие файлы и должны устанавливаться вместе. По умолчанию установка выполняется в текущий проект; добавьте `-g`, чтобы навыки были доступны во всех проектах. Агент можно указать явно: `-a codex` или `-a claude-code`.

Команда с GitHub устанавливает опубликованную версию. Для установки текущей локальной версии выполните из корня этого репозитория:

```sh
npx skills add . --skill '*'
```

Для навыков, установленных из GitHub, проверка и установка обновлений:

```sh
npx skills check
npx skills update
```

Команда `update` без имён обновляет все отслеживаемые навыки, включая другие наборы. Локальную установку обновляйте повторным `npx skills add . --skill '*'` из актуальной копии репозитория. Подробности — в [документации skills CLI](https://github.com/vercel-labs/skills/blob/main/docs/commands.md). Установщик запускается через `npx`; самим инструментам набора установка npm-пакетов не требуется.

### Ручное копирование

Скопируйте **все 12 папок `skills/yt-*` вместе** в каталог skills вашего агента: инструменты глав и удержания используют парсер из `yt-edit`, общий модуль запуска находится в `yt-script`, исследование ниши использует его классификатор, а правила выбора профиля находятся в `yt-voice`. Отдельное копирование `SKILL.md` даёт только текстовую инструкцию, без работающих проверок. Корневой `package.json` для запуска установленных инструментов не требуется.

Для Codex используйте `~/.agents/skills` либо `.agents/skills` в нужном проекте. Для Claude Code — `~/.claude/skills` либо `.claude/skills` в нужном проекте. Не смешивайте этот набор с английским оригиналом под теми же именами `yt-*`; сохраните прежнюю установку отдельно перед заменой.

Пример установки в Codex через PowerShell **из корня этого репозитория**. Если найдены существующие навыки с теми же именами, команда останавливается до копирования:

```powershell
$skillRoot = Join-Path $env:USERPROFILE '.agents/skills'
$skillFolders = @(Get-ChildItem -LiteralPath ./skills -Directory -Filter 'yt-*')
$conflicts = @($skillFolders | Where-Object { Test-Path -LiteralPath (Join-Path $skillRoot $_.Name) })
if ($conflicts.Count) { throw "Сначала сохраните или перенесите существующие навыки: $($conflicts.Name -join ', ')" }
New-Item -ItemType Directory -Force -Path $skillRoot | Out-Null
$skillFolders | ForEach-Object { Copy-Item -LiteralPath $_.FullName -Destination (Join-Path $skillRoot $_.Name) -Recurse }
```

Откройте новую сессию агента после установки. В Codex можно явно вызвать `$yt-script`, в Claude Code при установке как обычных skills — `/yt-script`. Каталог `.claude-plugin` также содержит манифесты для распространения как плагина; локальная разработка не публикует его автоматически.

Примеры запросов:

```text
Используй $yt-script. Напиши сценарий на русском на 5 минут:
как выбрать первый микрофон для домашней записи. Аудитория — новички.

Используй $yt-plan. Есть 6 часов в неделю и одна готовая запись.
Составь план производства без обязательной ежедневной публикации.
```

## Профиль автора — по желанию

**Свой файл имеет приоритет.** Передайте агенту `voice.md`, брендбук, описание тона или аналогичный документ под любым именем. Агент прочитает его на месте: переименовывать, копировать в `youtube/voice.md` или подменять шаблон не нужно. Если в проекте уже лежит профиль, агент проверит известные имена; при нескольких противоречащих профилях уточнит, какой относится к каналу.

Если профиля нет, при первом запросе, которому нужен авторский стиль, агент предложит выбрать: использовать готовый файл, создать профиль или продолжить в нейтральном стиле. Достаточно конкретный запрос он выполнит сразу; настройка не должна блокировать работу. После отказа предложение не повторяется в той же беседе. Для расчёта удержания или проверки таймкодов интервью не требуется.

Для создания или обновления используйте [yt-voice](skills/yt-voice/SKILL.md):

```text
Используй $yt-voice. Задай вопросы и создай профиль моего канала.

Используй $yt-script и мой файл docs/brand-tone.md как профиль автора.
Ничего не копируй и не меняй в профиле.

Используй $yt-voice. Составь профиль по этим двум сценариям
и сохрани его в profiles/my-channel.md.
```

Новый профиль без указанного пути сохраняется в `youtube/voice.md` рабочего проекта **только по запросу создания файла**. Это удобное место по умолчанию, не обязательный формат. Можно также заполнить [шаблон](templates/voice.md) вручную. Существующий профиль не перезаписывается без запроса на его обновление; глобальный профиль не создаётся. Выбор источника действует в текущей беседе, а в новой можно снова указать свой файл.

Русскоязычный канал не обязательно ориентирован на Россию. Регион, валюту и часовой пояс задаёт задача или профиль, а не язык.

## Инструменты

Команды ниже запускаются из корня набора. Входные файлы в примерах — ваши данные. Все текстовые файлы — UTF-8; входы допускают BOM. Команды одинаковы для Windows, Linux и macOS. Проверьте наличие подходящей версии командой `node --version`.

```sh
node skills/yt-script/hookscore.mjs --hook "Почему после экспорта звук становится тише?" --json
node skills/yt-package/title.mjs --title "Как записать чистый звук дома" --thumb "БЕЗ ЭХА" --json
node skills/yt-edit/deadair.mjs transcript.srt --json
node skills/yt-chapters/chapters.mjs transcript.srt --target 8 --duration 600 --json
node skills/yt-retention/retention.mjs retention.csv --axis seconds --json
node skills/yt-viral/swipe.mjs collected.json --min 2 --json
```

Каждая команда поддерживает `--help`. Ошибки входа возвращают ненулевой код; список глав с `valid: false` возвращает код 1, даже при JSON-выводе.

### Расшифровки

Монтаж, главы и сопоставление удержания принимают SRT, VTT и Whisper JSON:

```json
{"segments": [{"start": 0, "end": 3.5, "text": "Сейчас покажу, как настроить свет."}]}
```

Допускается также массив сегментов в корне JSON. Это пример формата, а не готовый набор для глав. Таймкоды должны возрастать; интервалы могут перекрываться. Предложения монтажа требуют проверки по видео: пауза может быть частью демонстрации.

В SRT/VTT удаляются теги оформления, декодируются числовые HTML-ссылки и распространённые именованные сущности. Редкие именованные сущности сохраняются как текст; полный словарь HTML5 не включён.

### Удержание

Нужны ровно два столбца: позиция и удержание. Пример с десятичной запятой:

```csv
Секунды;Удержание
0;100,0%
15;90,5%
30;85,0%
60;72,5%
```

`--axis seconds` означает секунды в первом столбце, `--axis percent` — проценты длины видео. Для пересчёта процентной оси во время добавьте `--duration 600`. Автоматическое угадывание оси отключено. Удержание — 85.5, а не 0.855; значения выше 100 допустимы. Разделитель определяется автоматически либо задаётся через `--delimiter ";"`, `--delimiter ","` или `--delimiter tab`.

Разница удержания измеряется в **процентных пунктах**. Интервал падения не доказывает причину ухода. Данные должны покрывать первые 30 секунд и начинаться с нуля для расчёта `hook_leak`; иначе значение `null`. Если в интерфейсе Studio нет нужного экспорта, можно передать агенту таблицу или график с осями; для графика вывод будет приблизительным.

### Подборка видео

`collected.json` — массив объектов `channel`, `title`, `views` (целое число), необязательный `url`. Для каждого канала нужно минимум четыре видео. Выбирайте сопоставимые форматы и возраст публикаций; не собирайте только хиты. Каналы с нулевой медианой пропускаются, дубликаты URL отклоняются. Медиана относится к переданной выборке, не ко всей истории канала.

## Что улучшено относительно оригинала

- Все инструменты работают на Node.js без внешних зависимостей. В версии 2.0 команды `python …/*.py` заменены на `node …/*.mjs`; флаги и структура JSON-отчётов сохранены. Обновляйте все 12 папок набора вместе, сохраняя свой профиль отдельно.
- Русские слова участвуют в оценке хуков, проверке повторов и выделении тем глав; ё и е сопоставляются.
- Восстановлена работа с JSON-массивом сегментов; добавлены UTF-8 BOM и понятные ошибки CLI.
- Удержание поддерживает десятичную запятую и явные единицы; потеря указывается в процентных пунктах.
- Пересекающиеся предложения монтажа не удваивают оценку экономии времени.
- Профиль автора необязателен; план подстраивается под ресурсы вместо фиксированного числа публикаций.
- Эвристики отделены от требований платформы и причинных выводов. Оценки хуков и заголовков **не предсказывают просмотры или CTR**; русская версия не калибрована на результатах каналов.

Проверенные 13.11.2026 первоисточники: [главы](https://support.google.com/youtube/answer/9884579?hl=ru), [трёхминутные Shorts](https://support.google.com/youtube/answer/15424877?hl=ru), [роль тегов](https://support.google.com/youtube/answer/146402?hl=ru), [лимиты метаданных](https://support.google.com/youtube/answer/57404?hl=ru). Порог длины обложки и оценочные баллы — редакторские рекомендации, не правила YouTube.

## Проверка разработки

```sh
node --test tests/*.test.mjs
```

Тесты используют синтетические данные, не статистику настоящего канала. Они проверяют кириллицу, сохранность кодировки, работу CLI, установку в отдельную папку и граничные случаи входных форматов. При наличии npm ту же проверку запускает `npm test`; предварительная установка пакетов не требуется.
